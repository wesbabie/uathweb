# UATH Landing Page — Next.js

A responsive homepage recreation based on the supplied UATH landing-page screenshot.

## Stack
- Next.js App Router
- React + TypeScript
- Tailwind CSS 4 (with custom responsive CSS)
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
